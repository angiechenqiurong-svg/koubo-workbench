# 口播工作台

为生活感悟类口播创作者准备的本机素材工具。粘贴抖音、B 站、小红书或 YouTube 分享链接，下载视频、提取中文文案，再校对、拆解和整理自己的创作。

**当前发行版：0.4.0。支持 macOS，本机运行。** 下载和本机文案提取不需要 AI 接口账户。Windows / Linux 尚未验证；当前不提供直接在线使用的网站。

## 可以做什么

- 粘贴抖音、B 站、小红书或 YouTube 单条视频网址或分享文字，尝试下载公开视频；成功率受平台限制和本机网络影响。
- 导入 MP4、MOV、WebM、M4V；单条上限 500 MB；重复素材不重复保存。
- 在本机识别中文口播；安装了可选字幕组件时，会结合画面文字生成字幕初稿。
- 按时间回看视频，编辑、保存、复制文案，下载视频，导出笔记。
- 复制整理好的请求到 ChatGPT，再把拆解、创作结果粘回来保存。
- 可选登录 ChatGPT，授权使用符合条件的 Plus / Pro 套餐额度，直接拆解或创作。
- 也可分别配置 OpenAI / 兼容接口、DeepSeek、Gemini 的 API 密钥。

## 安装和启动（Mac）

首次安装需要联网，并准备约 1 GB 空间。请先安装：

1. [Node.js 22 或 24](https://nodejs.org/zh-cn/download)（包含 npm）。
2. [Python 3.11 或 3.12](https://www.python.org/downloads/macos/)。
3. [Google Chrome](https://www.google.com/chrome/)。

下载项目：优先打开 [0.4.0 发行页](https://github.com/angiechenqiurong-svg/koubo-workbench/releases/tag/v0.4.0)，下载 `koubo-workbench-0.4.0-macOS-source.zip` 并解压。也可以在仓库页面选择 **Code → Download ZIP**。这是需要安装依赖的源码包，不是双击即用的独立 App。

1. 双击 **首次安装.command**。它会安装软件依赖和约 150 MB 的官方语音模型。视频处理组件自动安装，无需单独配置 FFmpeg。网络中断时可重新运行。
2. 安装完成后，双击 **启动口播工作台.command**。
3. 浏览器打开 `http://127.0.0.1:4317/`。启动窗口需要保持运行，关闭后重新双击即可。

首次打开脚本若被 macOS 阻止，请确认来自你信任的本仓库，再按系统提示允许打开；不需要关闭系统安全保护。通过 ZIP 下载后，若提示脚本没有执行权限，可在项目目录运行：

```sh
chmod +x *.command
```

画面字幕识别是可选功能，需要 Apple Command Line Tools。未安装时，工具仍可使用音频听写；安装开发工具后重新运行首次安装入口即可准备字幕组件。

## 使用步骤

1. 在顶部粘贴受支持平台的单条视频链接或完整分享文字。
2. 保持勾选“下载后自动提取口播文案”，点击“下载并提取”。
3. 如出现独立的 Chrome 窗口，请保持打开。遇到抖音验证码，需要你在窗口完成；工具不会自动解验证码，也不会读取已有浏览器的登录账户。
4. 下载后自动进入素材库；文案识别完成后，听原视频校对，再保存或复制全文。

抖音发布配文与视频口播全文分开显示。识别结果是初稿，可能有错漏；画面字幕时间是近似位置。平台访问限制、作品不可见或未完成验证，可能导致下载失败。暂不支持直播、图文、作者主页或批量链接，不保证去水印。仅用于你有权获取和使用的素材。

## 只有 ChatGPT 账户

有符合条件的 ChatGPT Plus / Pro 套餐时，可在 AI 设置选择“GPT / ChatGPT 套餐（登录授权）”，完成工作台发起的官方授权后直接拆解。仅在 ChatGPT 首页登录不能完成工具授权；需返回工作台看到已连接状态。详细步骤见文末。是否可用取决于账户、工作区、网络和实际授权结果。

也可以点击“复制给 ChatGPT”，手动粘贴到自己的聊天，再将完整 JSON 结果粘回工具。这个方式不需要接口密钥。

OpenAI API 密钥是另一个可选入口，使用 API 单独计费；ChatGPT 订阅不会自动提供 API 余额。DeepSeek、Gemini 也需要各自可用的密钥。云端拆解会向你选择的服务发送文案，下载和本机文案提取可以独立使用。

## 数据和隐私

视频、文案、设置保存在项目目录下的 `.local-data/`。本机识别时，音频和画面截图不上传到 AI 服务。下载时会访问对应视频平台；首次安装时会访问 npm、PyPI 和 Hugging Face。

发布源码不包含开发者的视频、样本拆解、接口密钥、Cookie 或运行数据。请备份自己的 `.local-data/`，不要将其中的设置文件公开。AI 密钥以仅当前用户可读写的文件权限保存，不回传浏览器或写入导出笔记。

## 开发者运行

```sh
npm ci
npm run setup:speech
npm run doctor
npm start
```

只体验导入、链接下载或已有文案整理，可以先跳过 `setup:speech`。未准备语音识别时，视频可以保留，准备完成后再提取。

```sh
npm test
npm run release:zip
```

自动化测试使用临时生成的视频和模拟 AI 服务，不发送真实用户素材。首次发布在 Apple Silicon / macOS 13 上验证了独立视频处理组件、测试流程和空素材库启动；其他 macOS 版本及 Intel Mac 的依赖由安装器提供，但尚未实机验证。

可选环境变量：`KOUBO_PORT`、`KOUBO_DATA_DIR`、`KOUBO_FFMPEG`、`KOUBO_FFPROBE`、`KOUBO_CHROME`、`KOUBO_PYTHON`（安装时）。服务固定绑定本机 `127.0.0.1`，不作为多人服务器使用。

## 反馈和贡献

欢迎通过 Issues 提交问题和需求，提供系统版本、操作步骤和错误提示。请先遮盖密钥、Cookie 和私人素材信息。提交修改前运行 `npm test`。

项目原创代码使用 [MIT 许可证](LICENSE)。外部依赖和模型按各自许可证使用，见 [第三方说明](THIRD_PARTY.md)。

### 提高识别准确度

完成首次安装后，可运行 `npm run setup:accurate`，下载约 480 MB 的官方 Small 模型。下载完成后，本机识别自动使用该模型，以语音识别为文案初稿，画面字幕用于对照，处理时间会增加；音视频仍留在本机。

在人名与专用词提示中填写视频实际出现的名字或术语，点击“保存词表”，再重新提取。该提示同时用于语音和画面字幕识别，不会强制替换同音字。校对页可展开语音与字幕对照，有差异的句子会提示回听。重新提取会保留一份旧文案，可用“恢复上次文案”恢复。


### 多平台链接与备用服务

支持抖音、B 站、小红书、YouTube 单条视频链接和分享文字。B 站分 P 链接保留 `p`，小红书链接保留必要的分享参数。请使用完整的分享链接。直播、私密作品及超过 60 分钟或 500 MB 的视频不在此版范围。

失败任务保留原分享文字，可直接重试或回填链接。抖音、小红书需要验证时会打开独立 Chrome 窗口，由你自行完成验证；不会读取主 Chrome 的登录 Cookie。窗口关闭后可再次重试，会话保存在本机。YouTube 是否能下载也取决于本机网络和平台访问条件。

在“AI 设置”里展开可选解析服务，填写 AnyToCopy 专业版的 API Key 和 API Secret，并明确启用，才会在本机解析失败后把分享链接发送给该服务。服务可能消耗会员额度；未启用时不调用。接口条件见 https://www.anytocopy.com/account/api/docs 。

全文可以直接编辑、复制和保存；时间与字幕对照在展开区域。同样段落数量的校对保留定位；重新划分段落会转为全文定位。识别可自动判断语言，也可指定中文或英语。提取后进入拆解不会自动购买或配置 AI 接口；未完成接口配置或 ChatGPT 套餐授权时，仍可使用 ChatGPT 手动接力。

### DeepSeek 与 Gemini 直接拆解

打开左下角“AI 设置”，在“文字 AI 服务”选择 OpenAI / 兼容接口、DeepSeek 或 Gemini。三家的模型和密钥分别保存在本机；切换服务后点击“保存设置”生效。DeepSeek 与 Gemini 自动填入官方地址和默认模型，模型名称也可以修改。

- DeepSeek：在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 获取接口密钥。调用协议见 [官方文档](https://api-docs.deepseek.com/)。
- Gemini：在 [Google AI Studio](https://aistudio.google.com/apikey) 获取接口密钥。使用原生 [generateContent 接口](https://ai.google.dev/api/generate-content)。需要本机网络能够访问 Google 的 API。

保存后重新打开设置，可点击“测试已保存的接口”。测试仅发送连接检查文字，可能消耗少量额度；不会发送素材。配置可用后，点击“AI 拆解”会先弹出服务选择窗口。选择 DeepSeek、Gemini 或 OpenAI / 兼容接口后点击“开始拆解”，本次请求只调用所选服务，不改变默认配置。未配置的服务会提供对应的配置入口。“生成稿子”使用设置中的默认服务。没有密钥时仍可使用手动复制方式；填入模型名称本身不能让接口开始工作。

本机语音提取继续独立运行。云端语音识别使用保留的 OpenAI / 兼容接口配置，不会把 DeepSeek 或 Gemini 的文字密钥发给语音接口。清除密钥只影响当前选中的文字服务。

## 在本机使用 ChatGPT 套餐

本版包含官方 [Sign in with ChatGPT](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt) 授权流程，是否可用由账户、工作区和实际授权结果决定。

1. 在 AI 服务设置中选择“GPT / ChatGPT 套餐（登录授权）”。
2. 查看授权信息的本机保存位置，勾选同意保存，点击 **Continue with ChatGPT**。
3. 在官方页面登录，选择账户及工作区，允许工作台使用套餐额度。返回后会显示连接状态及账户可用模型。
4. 点击“测试 ChatGPT 连接”可发送一句检查请求；拆解和创作需手动点击开始。保存设置可将它设为默认文字服务。

授权记录单独保存在 `.local-data/chatgpt/`，不返回给网页前端，也不会包含在发行包中；可在设置中切换已保存账户或断开连接。套餐调用走官方 Responses API，使用套餐额度，受账户及应用额度限制；不会自动切换到 API 密钥计费。ChatGPT 套餐授权不支持语音转录，可继续使用本机文案提取，或单独配置 OpenAI 语音接口。
