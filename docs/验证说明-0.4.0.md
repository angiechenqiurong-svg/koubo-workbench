## 每次拆解选择服务（2026-10-14）

点击“AI 拆解”先打开选择窗口，列出 DeepSeek、Gemini 和 OpenAI / 兼容接口及各自的配置状态，点击开始才提交文案。未配置时直接打开对应服务的设置，不自动切换调用其他服务。请求携带本次 provider，服务端验证选择并使用该服务独立密钥，不修改默认设置；正在运行的请求保留开始时的服务配置。

界面测试验证打开、取消、选择时无拆解请求，确认后提交指定 provider，未配置入口正确，余额不足提示与默认服务不变。完整服务测试验证默认 Gemini 时可指定 DeepSeek 拆解，默认 DeepSeek 没密钥时可指定已配置的 Gemini，非法 provider 和缺少密钥不会发送外部请求。测试使用模拟服务，不消费真实账号额度。
